## 1. 建筑「耗能/工作」开关（地编 `POWERED_ON`）

地图页选中一栋楼 → 「开关」那一行直接读、直接切：

```
开关   GAPILE (61,61)：耗能/工作 = 1（通电）   [⚡ 通电] [⛔ 断电] [🔍 扫描全档断电]
```

- `0` = 这栋**不能生产单位、不能用武器、不播工作动画**（发电建筑照样发电）；
- 落点 = 建筑记录 `base+1580`（`HasPower`），并**同时写** `+1684 WasOnline` / `+1718 StuffEnabled` ——
  只写一个会被引擎按实时电力重算抹平；
- ⚠ 电厂改不动（发电建筑不吃电，引擎强制算成通电），界面会直接告诉你；
- 依据：两座兵营对照档（地图 0/1）+ 游戏内验收「0 的那座造不了兵」。

## 2. 所属方属性：IQ / 科技等级 / 起始资金 / 玩家控制

「所属方金钱」页选中一行 → 下方四个控件自动读出，可改：

| 控件 | 范围 |
|---|---|
| IQ | 0–5 |
| 科技等级 | 0–10 |
| 起始资金 | 0–2147483647（地编 `Credits` × 100） |
| 玩家控制 | 是 / 否 |

**起始资金 ≠ 现在有多少钱**（后者是列表里「金钱」那一列），改它只影响开局给多少。

## 3. 行为 106「设置科技等级」能看能改了

以前参数框是空的。原因：这个行为有**两个**参数，一个还是字符串。

| 地编那一栏 | 存档位置 | 类型 |
|---|---|---|
| 科技类型 | 行为对象 `+104` | 8 字节 ASCII |
| 数值（等级） | 行为对象 `+164` | int32 |

- 编辑器里多了一行「科技类型」，**只在 106 时出现**；
- **下拉 561 项，从规则文件读**（建筑 403 + 载具 80 + 步兵 67 + 飞机 12），带中文名：
  `AEGIS 神盾巡洋舰`、`GAPOWR 发电厂`、`E1 美国大兵`；
- 散文件优先、MIX 数字大优先、加密 MIX 自动解密 —— **不需要自己解包**，装 Mod 也读你那份规则；
- 等级口径：**0–10 可建造；-1 或大于 10 = 不可建造**（界面会标出来）。

## 4. 顺带修掉的

- 行为列表「行为类型」列对 125/106 会显示成 `GAPOWR`/`AEGIS`（误读了名称槽）；

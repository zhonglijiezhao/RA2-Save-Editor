## v1.2.1（内部构建 p220）

一个小版本，只做一件事：**别再把单位放到游戏里看不见的地方**。

### 新增

- **「蓝线」可见区域校验**（地图页）
  - 判定依据 = 地图 `[Map]` 里的 `LocalSize`（就是地编「地图参数 → 可见区域」那一项）
  - 换算：**编辑器格坐标 = 地编坐标 × 2**。例如 `LocalSize=5,4,174,107`
    ⇒ 编辑器坐标 `x 10..357、y 8..221`
  - **放单位 / 粘贴 / 移动** 到界外时弹确认框，写明可见区域与换算范围，你点继续才动手
  - 点格子时，若该格在界外，信息栏第一行会显示 `⚠ 在蓝线外（游戏里不显示这块地图）`

### 判定顺序（以地图为准）

1. **当前地图页打开的那张地图**（你手动换过图就按你眼前这张）
2. 存档对应的地图（同名目录 → 游戏目录）
3. 已挂载的地图对象

**都找不到 ⇒ 不做任何判断，也不拦人**（不猜）。

### 说明

- 校验只“提醒”，**不会擅自改你指定的落点** —— 与之前「我指定是平地，你就别挪」的口径一致。
- 地图数据只读一次并缓存，换图自动重新读取。

## 科技类型下拉有内容了 —— 561 个建筑/单位，还带中文名 🏭

上一版把行为 106 接上了，但「科技类型」那个框是**空的**，只能手打类型 ID。
这一版把它填上：**从游戏目录的规则文件读**，跟地编一样能选。

### 下拉里是什么

| 来源 | 条数 |
|---|---|
| `[BuildingTypes]` 能建造的建筑 | 403 |
| `[VehicleTypes]` 载具 | 80 |
| `[InfantryTypes]` 步兵 | 67 |
| `[AircraftTypes]` 飞机 | 12 |
| **合计（去重后）** | **561** |

显示成 **`类型ID 中文名`**，跟地编一致：

```
GAPOWR 发电厂
GAPILE 盟军兵营
AEGIS 神盾巡洋舰
E1 美国大兵
CALAB 爱因斯坦实验室
```

中文名取自 rules 里每个类型的 `UIName=`（CSF 标签）→ `ra2md.csf` 的正文。
**注意是 `UIName=` 不是 `Name=`** —— `Name=` 是英文名（`Aegis Cruiser`），
一开始取错了字段，一个中文名都拿不到，这是踩过的坑。

### 规则文件怎么读（不需要你解包）

走工具已有的 `game_lists()` 那条路：**散文件优先 → MIX 文件名数字大的优先
（`expandmd99` 压 `expandmd90`）→ 加密 MIX 自动解密**（Westwood RSA + Blowfish，纯标准库）。

所以：

- 装了 Mod、改了 `rulesmd.ini`，下拉里就是**你那份规则里的类型**；
- 存档在哪个任务目录，就按那个目录往上找规则（`以游戏下的规则为准`）；
- 一个都找不到时，下拉退化成空、框仍可手打（不会报错，也不会把候选写死成原版列表）。

三种注册写法都认：`12=GAPOWR`、`+=SCHP1`（Ares/Phobos 追加注册）、
`SCHP1=SCHP1在扩展平台中`。`;注释` 掉的条目会跳过。

### 写入时自动剥中文名

存档里那个槽只有 **8 字节 ASCII**，所以写之前只取第一个词：

| 你填 / 选的 | 实际写进存档 |
|---|---|
| `AEGIS 神盾巡洋舰` | `AEGIS` |
| `AEGIS-神盾巡洋舰` | `AEGIS` |
| `aegis` | `AEGIS` |
| ` GAPILE 盟军兵营 ` | `GAPILE` |

所以带不带中文名、大小写、两侧空格，都不影响落盘的值。

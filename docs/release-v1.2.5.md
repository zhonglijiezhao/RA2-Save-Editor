# v1.2.5 — 覆盖物（矿/墙/桥）全部就位：能看见、能拦住

这一版的主角是**覆盖物**。上一版我判断"覆盖物不在存档里"，是错的 —— 这次用两张地图的
`[OverlayPack]` 真值逐格比对，把它在存档里的位置钉死了，并顺手把整条链路做完：

- 存档里读得出每一格有什么覆盖物（矿/宝石/围墙/沙袋/铁丝网/桥面/铁轨/石头…）；
- 地图页把它们**画出来**；
- 手动放置单位时，**墙类不再允许放**（地编也不让放，强放会报错）；
- 刷兵（小队法）**什么都不做** —— 引擎自己会把落点挪到相邻格。

另外三件事一起进这版：**存档地形**（不依赖 .MAP 也能出图，地形来源三档可选）、
**树/石（Terrain 对象）显示**、以及大盘地形渲染的一处读法 bug 修复。

## 1. 覆盖物在存档里的位置：格对象 `+0x58`

| 偏移 | 宽 | 含义 | 空值 |
|---|---|---|---|
| 格对象 `+0x58` | u32 | **OverlayTypeIndex**（`[OverlayTypes]` 的行号） | `0xFFFFFFFF` |

索引就是 `rules(md).ini` 里 `[OverlayTypes]` 段 `N=名字` 的 **N**（YR 共 250 项）。
例：`112 = TIB08`（矿石）、`30 = GEM03`（宝石）、`241 = BRIDGEB1`、`203 = FENCE20`、
`77..104 = LOBRDG01..28`（低桥）、`171..175 = SROCK`（石头）、`42..61 = TRACKS`（铁轨）。

### 定案证据（两条独立，都是"地图真值逐格比"）

1. `ALL01UMD.sav` × `all01umd.map`（同一张图，6 万格）：地图解出 **1525** 个覆盖物格，
   与 `+0x58` 逐格比对 **1513 / 1525 = 99.2%** 完全相等；59515 个空格里 59503 个是 `0xFFFFFFFF`。
   剩下 12 个不符的是"地图写了宝石、存档里被挖掉了"，属正常差异。
2. 玩家档 `SAVE4823.SAV` 的 `+0x58` 里 **14 个 `0x70`（112 = TIB08 矿石）**，
   而同一批测试图 `2.map` 的 `[OverlayPack]` 正好也是 **14 个 112**。

### 上一版为什么扫漏

上一版用"同一 tile 下这个字段是否恒定"筛字段。可**覆盖物本来就与地形强相关**
（矿只长在特定 tile 上），所以 `+0x58` 的恒定率也是 0.99+，被当成"地形派生"误杀。
教训：判"某字段是不是某种物件"必须拿**物件真值逐格比**，不能用 tile 相关性。

## 2. 地图 `[OverlayPack]` 的压缩也解对了（LCW / Format80）

地图里的覆盖物是 **512×512** 的压缩位图（索引 `y*512+x`，`0xFF` = 空），32 块 × 8192 字节。
之前卡在"解出 259707/262144、值里有乱码"，根因是 **cmd4 是 4 字节的"填充"命令**，我当 3 字节处理 ⇒ 整条流错位。

| 命令 | 字节 | 编码 | 语义 |
|---|---|---|---|
| cmd1 | 1 | `10cccccc` | 字面量 `cc` 个；`0x80` = 结束 |
| cmd2 | 2 | `0cccpppp __` | count=`c+3`；offset = `((b&0x0F)<<8)｜下一字节`（12 位） |
| cmd3 | 3 | `11cccccc __ __` | count=`c+3`；Pos=u16 |
| **cmd4** | **4** | `0xFE __ __ __` | **把最后一字节重复 u16 次** |
| cmd5 | 5 | `0xFF __ __ __ __` | u16 count + u16 Pos |

空块压缩后正好 7 字节：`81 FF | FE FF 1F FF | 80` = 1 + 8191 + 结束 = 8192 ✓
有矿块 36 字节 → 1+3660+3+509+3+509+512+513+2482 = 8192 ✓（字节正好吃完）

## 3. 地图页把它们画出来了

勾选框「**覆盖物**」（默认开）。颜色只按"挡不挡路"分档：

| 样式 | 含义 |
|---|---|
| 金黄圆点 | 矿 / 宝石（不挡路） |
| **深灰方块** | **一切挡路的**：围墙 / 沙袋 / 铁丝网 / 石头 / `Land=Rock` 类 |
| 蓝圆点 | 桥面 / 铁轨 / 低桥（改地块但能走） |
| 浅灰圆点 | 其它（如 `DUMMY15`，无 INI 段） |

图层次序：地形 → 路径点 → **覆盖物** → 树/石 → 单位 → 选中框；低于 3 倍不画。网格模式（没挂地图）也画。

## 4. 墙类不让放 · 刷兵什么都不做

- **手动放置 / 粘贴 / 移动**：落点有挡路覆盖物 → **直接拒绝**（弹的是警告，不是"仍要继续"），
  并告诉你"最近的空置格是 (x,y)（n 格远）"，但不替你改落点。
- **刷兵（小队法）**：**不判覆盖物、不挪格** —— 刷兵是引擎自己造单位，落到墙/石头上时
  引擎读档会自己改到相邻格；编辑器抢先挪反而把玩家指定的路径点改掉了。
- **矿/宝石不拦**（矿不影响放置单位和建筑）。

挡路判据全部来自 `rules(md).ini`，四条：

| 判据 | 例子 |
|---|---|
| `Wall=yes` | GASAND 沙袋、GAWALL/NAWALL 围墙、CAFNxx、CAKRMW、GAFWLL |
| `IsARock` | SROCK / TROCK / LUNRK 石头 |
| `Land=Rock` / `Land=Water` | FENCE01..22 装饰围栏、PALET、DRUM、WCRATE |
| 无 INI 段的硬编码墙 | CYCL 铁链网、BARB 铁刺、WOOD 木墙、FENC 铁丝网 |

## 5. 存档地形（§278–§280）

- 格对象 **`+0x4C`(u16) = tile 索引**、**`+0x12F`(byte) = 层高**（旧代码读的是低字节，一直读错）。
- 只凭存档就能渲染地形，与用 .MAP 渲染**只差 1.10% 像素**。
- 地图页多了「地形：**地图 / 地图+存档补格 / 存档**」下拉：
  · 地图 = 完全用 .MAP（与存档无关，换档同一张地形）
  · 地图+存档补格 = 地图为主，补上地图里没有的格
  · 存档 = 只用存档算的结果（与游戏画面最接近）
  没 .MAP 时自动降级到"存档"，并在标题栏写明。

## 6. 树 / 石（Terrain 对象，§281）

- 独立对象类（244 字节、无伴随）：坐标 `+0xB0/+0xB4`、HP `+0x80`、类型指针 `+0xDC`。
- **占格**（格 `+0x138` 的 `0x10` 位）⇒ 那格不能放东西；`cell_taken` 已纳入。
- 地图页勾「树/石」显示（默认关 —— 一张图动辄 3000+ 棵）。

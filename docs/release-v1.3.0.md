## 1. 先说最重要的：删建筑不再弹框

**症状**：用上一版删掉一栋建筑，存档能存、能重开，但一进游戏读档就弹 `Internal error`。
游戏目录的 `except.txt` 里是 `EXCEPTION_INT_DIVIDE_BY_ZERO @ 006CF3DD`。

**根因**（反汇编 gamemd 确认）：

```
0x6CF3CF  MOV [ESP+0x10], 0     ; ← 除数手工置 0
0x6CF3D7  MOV EAX, 1
0x6CF3DC  CDQ
0x6CF3DD  IDIV [ESP+0x10]       ; ← 崩在这
```

这不是"某个计数变成 0"，而是 **MSVC 的断言陷阱**（故意除零让进程死）。它所在的
`FUN_006cf350` 是"**两张键列表归并对齐**"的例行程序，逐项比对 `[count][key×count]`；
**两边错位就跳断言** ⇒ 存档里有一张键表比实际对象多了一条（悬空键）。

**漏在哪**：删建筑时会剔掉三张登记表里的键，但判据是"表里要命中 ≥8 个不同建筑键（只抽样 24 个）"。
大图里会存在"混合登记表"（建筑键、单位键、触发键混在一张，本档是 228 条），
建筑键占比低 ⇒ **整张表被滤掉** ⇒ 少剔一处 ⇒ 读档必爆。小图凑不出这种表，所以之前一直没事。

**这版怎么做**：

| 措施 | 说明 |
|---|---|
| 兜底扫尾 | 删完后对**每张认得出的键表**再剔一遍（每删 4 字节重新定位，防止偏移前移） |
| 二级扫尾 | 第一轮跑完还有残余 ⇒ 自动再来一轮 |
| `leftover_refs()` | 明确回答"这个键在明文里还剩几处"，**干净的唯一标准 = 0 处** |
| `sweep_key_refs()` | 把残留键从所有表里剔干净（也能救已经坏掉的档） |
| **保存闸门** | 只要还有清不掉的残留键，`save()` **直接拒绝写盘** —— 宁可不让存，也不给你一个进游戏必弹框的档 |
| 界面出口 | 删完若真有残留，弹窗直接问「要不要现在清掉？」，点是就地剔干净再复查 |

> 如果你手上有"上一版删过建筑、进游戏弹框"的档：用新版打开 → 删一栋建筑触发一次清理，
> 或者直接把档发我，`sweep_key_refs()` 一条命令就能救。

## 3. 没有 .MAP 也能画地形

**结论：能。** 地形全在存档的格对象里，不需要地图文件：

| 数据 | 位置 | 实测（`ALL01UMD.sav` × `all01umd.map` 逐格比） |
|---|---|---|
| 地形 tile 索引 | 格对象 `+0x4C`（u16） | 与地图 `[IsoMapPack5]` 一致 **97.7%**（55,873 / 57,194） |
| 层高 / 台地 | `+0x12F` | **100%** |
| 地形变体 | `+0x100` | 引擎运行期挑的同族变体 |
| 覆盖物（矿/墙/桥） | `+0x58` | §283 已定案 |
| 尺寸（W,H） | 存档头 `0x348E` + 格坐标反推 | 与地图 `[Map] Size` 同口径 |

- 地图的 57,194 格**全部**在存档里（差集为空）；存档比地图**多 3,836 格**（引擎补的边界/填充格）。
- 那 2.3% tile 不一致不是读错，是引擎运行期换成了同族变体 —— **存档里的值才是游戏里真正显示的那个**。

**唯一真缺的是「剧场」**：tile 索引按剧场取色，而存档里没有这个字段
（39MB 明文里搜过 `TEMPERATE` / `SNOW` / `URBAN` / `Theater` / `[Basic]`，连 UTF-16 版本都搜了，
唯一命中的是建筑名 "LA Movie Theater"）。所以地图页多了一行：

- **地形数据源**：`地图` / `地图+存档补格` / `存档`
- **剧场**：`TEMPERATE / SNOW / URBAN / NEWURBAN / DESERT / LUNAR`
- 有 `.MAP` 时用地图 `[Basic] Theater`；没有时默认 `TEMPERATE`，可手选。
- **剧场只影响配色** —— 格子归属、层高、选位、放置判定都不看它，选错也能照常干活。

> 坑：像 `SAVE4823.SAV` 这种空档，12,720 格里 12,695 个 tile = 0 ⇒ 只能画出一个纯色菱形。
> 不是读错，是存档里本来就没有地形数据。

## 5. 地图页：7 行散控件 → 四张分区卡

地图页原来把 30+ 个控件平铺成 8 行，好几行直接超出窗口右缘。现在：

| 分区 | 里面有什么 |
|---|---|
| **地图** | 选择地图 / 自动匹配 / 用地编打开 / 备份存档 ＋ 地图状态；地形数据源 + 剧场 |
| **视图** | 缩放 － ＋ / 适应窗口 / 网格 / 覆盖物 ＋ **叠加 ▾**（路径点 / 单位 / 树石）/ 重绘 |
| **放置** | 建筑（类型 / 刷新 / 所属方 / 放置 / 删除 / 改所属方）· 单位（单位 / 所属 / 等级 / 放单位 / 挪平地 ＋ **更多 ▾**）· **触发法**开关 + 事件 ＋ **修旧楼 ▾** |
| **选中格** | 复制 / 粘贴 / 移动到此格 / 删除该格单位 ＋ 剪贴板状态 |

关键：分区标题在**左侧竖列**，所以分组**不额外吃高度**（不像四张普通卡片各多一行标题）。
画布高度基本没变，但每张卡里"这堆东西是干什么的"一眼就清楚。

顺手挖出并修掉一个**全局**问题：`clam` 主题给按钮埋了 `-width 11`（字符），
**所有按钮最小 105px** —— 这才是"按钮傻大、一行塞不下几个"的根因。改成按文字自适应后，
两字按钮 105 → **52px**，触发页那一排 9 个按钮、赠送页那两行超宽控件，全都自动变宽松了。

另外：地图页那行 50+ 字的地图状态拼接精简为「文件名 ✓/⚠」（完整口径进状态栏 + 说明）；
赠送建筑页两行（需 ~1010px）拆成三行；画布下提示的 `wraplength` 980 → 700（工作区只有 722）。

## 7. 升级提示

- 这是 **v1.2.6 之后的大改**（界面 + 地图页 + 一个毁档级 bug 修复），建议直接替换。
- **铁律没变**：本工具**只读地图、只写存档**，任何情况下都不写 `.map/.mmx/.yrm/.mpr`
  （写盘函数只留壳，调用即抛 `MapWriteForbidden`；`save()` 也会拒绝地图扩展名）。
- 改档前请备份。地图页有「备份存档」一键按钮。
- 解压后**直接双击 `RA2存档编辑器.exe`**（`_internal` 目录要跟它同级，别只拷 exe）。

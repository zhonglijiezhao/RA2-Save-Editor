## 修好了：行为 106「设置科技等级」现在能看、能改 ✅

玩家 2026-11-17 反馈：触发器编辑器里选到 **106 设置科技等级**，
参数框是空的、什么都填不进去（截图里那个橙色框）。

原因不是"没做这个行为"，而是**这个行为的参数不是一个数**：

| 地编那一栏 | 存档里在哪 | 类型 |
|---|---|---|
| 科技类型（AEGIS-神盾巡洋舰） | 行为对象 **`+104`** | **8 字节 ASCII 字符串** |
| 数值（等级） | 行为对象 **`+164`** | int32 |

工具以前只认"参数 = `+72` / `+164` 里的一个数"，科技类型那个**字符串槽**根本没读，
所以界面上只能看到一个空的参数框。

顺带还暴露了另一个毛病：行为列表的「行为类型」列读的是 `+104` 那个字符串
（本来是给行为 125「将建筑建于」存建筑类型名用的），于是 125/106 那两行的类型名
会显示成 `GAPOWR` / `AEGIS` 这种乱入的文字 —— 这版一并改成正式的中文名。

### 现在长这样

```
行为类型 [106 设置科技等级(科技类型)[等级] ▾]  参数 [5 ▾]  [改选中] [添加] [复制] [删除]
科技类型 [AEGIS ▾]  （上面的「参数」= 等级 0–10；这里 = 科技类型名，如 AEGIS / GAPILE）

 #  类型   行为类型                        参数   参数含义
 1  106    设置科技等级(科技类型)[等级]      5     AEGIS 等级 5
```

- 选中一条 106 行为 → 两个框自动回填（`AEGIS` + `5`）；
- 「参数」下拉 = 等级 **0–10**；「科技类型」= 自由填的类型 ID（自动转大写、超过 8 字符截断）；
- 这行**只在 106 时出现**，换成别的行为会自动收起来（跟「路径点」那行的做法一致）；
- 新建 / 修改都会把两个值一起写：科技类型 → `+104`，等级 → `+164`，同时把 `+72` 清 0。

### 证据

玩家给的 `SAVE0BB3.SAV`（另有同图的 `ALL01UMD.sav`）里，触发 `01000000` 的 106 行为：

```
+104..+111 = 41 45 47 49 53 00 00 00   → "AEGIS"
+164       = 5                          → 等级
+72        = 0                          → 参数确实不在这儿
```

与地编截图（科技类型 = AEGIS-神盾巡洋舰、数值 = 5）逐项吻合。

# v1.2.6 — 铁律落地：**本工具只读地图、只写存档**

这一版没有新功能，只做一件事，但它是长期规矩：

> 玩家 2026-10-27 00:20：「记住一个铁律！**任何情况下存档编辑器都不允许有向地图中写入数据的能力**」

上一版（v1.2.5）里还带着"把局部变量名/默认值写进地图 `[VariableNames]`、把路径点写进
`[Waypoints]`、改完重算 `[Digest]`"这套能力 —— 这版**整套删除**。

---

## 1. 删了什么

| 原能力 | 现在 |
|---|---|
| 写地图 `[VariableNames]`（变量名 + 开局默认值）并重算 `[Digest]` | 写盘实现**删除**，函数只抛 `MapWriteForbidden` |
| 写地图 `[Waypoints]`（把存档路径点同步进地图） | 同上 |
| `register_waypoints_to_map()` | 只抛异常 |
| `define_local_var(..., write_map=True)` | 参数**删除**；现在只写存档（名字 + 当前值） |
| `ensure_local_var(..., write_map=)` | 参数删除，只写存档 |
| `set_local_var_default()` / `remove_local_var()` | 只抛异常；清存档侧改用 `clear_local_var()` |
| `make_local_var_recipe(..., write_map=)` | 参数删除 |
| `SaveDoc.save(out_path)` | 新增总闸：目标以 `.map/.mmx/.yrm/.mpr` 结尾 ⇒ 直接拒绝 |

**为什么是"删代码"而不是"加开关"**：开关会被绕过、会被忘记。把写盘代码删掉、把函数留成
只抛异常的壳，任何旧调用（包括我以后手滑写的）都会**当场炸**，而不是静默改你的图。

## 2. 「局部变量」页跟着改

- 标题：**局部变量（只写存档 · 本工具不写地图）**
- 页面顶部四行写清规矩：
  - 能做：① 给某一号起名字　② 改它的当前值 —— 都只写进存档；
  - 做不到（也不许做）：把名字/默认值写进地图 `[VariableNames]`；
  - 不写地图照样能跑：触发用的是**引擎索引号**，名字只是给人看的，读档以存档为准。
- 按钮：`✏ 写名字+初值…（写存档）`、`存档值置 1`、`存档值置 0`、`🧹 清空这一条（写存档）`；
  「默认值…（写地图）」「🗑 从地图删除」**已删除**。
- 地图那一行改成「只读参考（本工具不写地图，一个字节都不改）」。
- ★顺手修：这个窗口原来 `760×640`，实测需要 **686 像素高** ⇒ 底部三行关键说明被挤掉、
  玩家根本看不到。已改成 700。

## 3. 澄清上一版一句错话

上一版列表下面写着「只在存档镜像里有名字的 N 条（**那些读档会消失**）」——**这句是错的**：

- 反汇编：`LoadLocalVariableNames 0x689B20` 的唯一调用者在**地图读/写**路径（紧跟写
  `Ranking`/`ParTime`），**不在读档路径**；
- 实测（§176.4 探针 D）：变量在地图里默认 1、存档里 0 → 事件 36 **不响应** ⇒ 读档取的是存档值。

⇒ 存档自足，地图不会在读档时覆盖它。所以 `V1 / 仅存档` 的含义只是"这个档里有名字、
这张图里没定义"，**照样能跑**，只是 FA2 里选不中。要选得中，请你自己在 FA2 里加一个同名变量。

## 能给建筑「断电」了 —— 地编的「耗能/工作」，现在存档里也能改 ⚡

地编的建筑属性里有一栏 **「耗能/工作」**（`POWERED_ON`）。
填 0 的楼：**不能生产单位、不能用武器、也不播工作动画**；但**发电建筑照样发电**。

以前只有地图编辑器能设它，而且**对已经存好的档没有用** ——
这一版把它做进存档编辑器：地图页选中一栋楼，直接看状态、直接切。

### 怎么用

地图页（导航栏「地图 · 选位」）→ 「放置」区最下面多了一行：

```
开关   GAPILE (61,61)：耗能/工作 = 1（通电）   [⚡ 通电] [⛔ 断电] [🔍 扫描全档断电]
```

- **点选任意一格建筑**，标签就显示它的当前值（0 / 1）；
- 点「⚡ 通电」或「⛔ 断电」→ 确认框写着「当前值 → 目标值」→ 写入；
- 「🔍 扫描全档断电」列出所有 = 0 的楼，可一键全部通电；
- 改完照例**另存为新文件**，原档不覆盖。

### 为什么是三个字节，不是一个

只改一个「开关位」是没用的：引擎每次 Update 会比较 **HasPower** 和 **WasOnline**，
两者不一致就判定"状态变了"，按当前电力**重算一遍**，把你写的值抹平。
所以工具一次写三个：

| base 偏移 | 对象偏移 | 类成员 | 作用 |
|---|---|---|---|
| `+1580` | `+0x660` | `HasPower` | 当前是否有电（就是地编那一栏） |
| `+1684` | `+0x6C8` | `WasOnline` | 上次 Update 的状态（不一致会触发重算） |
| `+1718` | `+0x6EA` | `StuffEnabled` | 建筑被 Enable/Disable 的档位 |

三个写成同一个值，引擎就认为"状态没变化"，原样保留。

### ⚠ 发电建筑改不动（工具会直接告诉你）

**电厂（GAPOWR / NAPOWR 等）本身不吃电**，引擎强制把它算成"通电"。
实测：同一张地图里两座电厂分别写 0 和 1，存档里都是 **1 / 1**，逐字节比完 69 处差异里没有一处 0/1。

所以这个开关只对**耗电建筑**有意义：兵营、工厂、雷达、防御塔……
选中发电建筑时，标签会写「发电建筑（不适用）」，按钮也会再确认一次。

### 证据

玩家 2026-11-17 做了对照档：一张 80×80 的小图放**两座兵营**，
地图里 `[Structures]` 一座 `POWERED_ON=0`、一座 `=1`，游戏自己存盘后交过来。

| | (59,68) | (61,61) |
|---|---|---|
| 地图 `POWERED_ON` | 0 | 1 |
| 存档 `+1580` | **0** | **1** |
| 存档 `+1684` | 0 | 1 |
| 存档 `+1718` | 0 | 1 |

游戏内验收：**`= 0` 的那座兵营点开造兵，造不了**；`= 1` 的正常。
再把 `= 1` 那座改成 0（三字节同写）→ 同样造不了 ⇒ 定案。

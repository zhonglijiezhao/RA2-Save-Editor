## 1. 新页：武器 · 弹头

左侧 213 把武器（本档），可搜索、可「只看 ≠rules」（存档里的值和 rulesmd.ini 不一样的）；
右侧能改三样东西，还能逐项改 11 种装甲的克制系数：

| 能改 | 说明 |
|---|---|
| 伤害 | 1~100000 |
| 射速（ROF） | **帧，越小越快** |
| 射程 | 1/8 格精度，上限 255 格（超过游戏自带的 40 格会给提示但不拦） |
| 11 项克制表 | none / flak / plate / light / medium / heavy / wood / steel / concrete / special1 / special2，按百分比 |

还有两个小按钮：「按 rules 还原」把这一把改回 rulesmd.ini 的值；
「哪些型号用这把武器」列出规则里拿它当主/副/精英武器的单位。

### 为什么改这里有用，改 rulesmd.ini 反而没用

- 你以为：改 `rulesmd.ini` 里 `[PrismShot] Damage=999`，读档就变强
- 实际：**已存盘的存档不认**（玩家实测）。读档时引擎用的是**存档里自带的那份数值表**
- 所以：本工具改的是存档里那份 ⇒ **只影响这一份存档**，不动游戏文件、不影响别人、
  也不影响新开的局

### 顺带说清楚三件事

1. **单位身上没有武器**——只有型号/等级/血量/归属/坐标。武器挂在"型号"（类型对象）上
2. 本档有 **13 把武器和 rulesmd.ini 不一致**（比如 SonicZap 伤害 100→4、Maverick3 1100→750）。
   这不是工具读错，存档存的是**存盘当时的有效值**（地图 INI / MIX 覆盖也算）
3. 射程那个 64 格上限**是我的护栏，不是引擎限制**。实测游戏自带最大 40 格、
   本档最大 25 格；字段本身是 u32，塞多大都不会溢出。已放宽到 255 格（地图只有 200×200）

## 2. 四个真 bug（都是"看着正常、其实必坏"的那种）

| 问题 | 症状 |
|---|---|
| 克隆添加单位时的警告列表没初始化 | 走到"本档没有该移动方式模板"的分支**必抛异常** |
| 单位下拉的类型名被同名方法覆盖 | 下拉里显示的是 `E1` 这种**裸 ID**，不是"美国大兵"，等于这个功能没了 |
| 保存前的块布局自检只算不判 | 自检结果算出来了，但**没有任何地方看它** ⇒ 等于没做 |
| 规则文件路径写死开发者机器 | 玩法把游戏装在别处（或没装 `D:\py`）⇒ 可建造判定/血量等静默失效 |

最后一条现在改成：优先用你填的「游戏目录」→ 存档所在目录 → 上一级 → 内置兜底。
配套：**游戏目录会记住**，下次开程序不用再填。

## 3. 数据安全：改了一半就关窗的日子结束了

对"改存档"的工具来说，这块比性能重要得多。

- **关窗前会问**：改了没保存点 × ⇒ 弹「是（去保存）/ 否（丢弃）/ 取消」
- **换档前也会问**：同上
- **标题栏有 `*`**：`— 文件名 *` 就是有未保存改动
- 判据用的是新增的 `modified()`，不是 `dirty()` —— 实测「改路径点」改了明文但 `dirty()`
  返回 False，用它的话这条保护会漏

顺带修掉一个更阴的 bug：**另存为之后，再点「原地保存」会覆盖原档**。
原因是保存成功后没把内部基准（明文/路径/块表）推进到新文件。
现在保存完会同步推进，并且 `*` 标记能正常消掉。

### 另外

- **快捷键**：`Ctrl+S` 另存为 / `Ctrl+O` 打开 / `F5` 刷新
- **另存为不再撞名**：默认名以前会滚成 `65_修改_2_修改_2_修改`，还会弹「要替换吗」吓人。
  现在先剥干净尾部 `_修改/_N` 再拼一次，磁盘已存在就往后让号
- **事件 / 行为页加滚动条**：大任务档上千条以前只能靠滚轮

## 4. 性能：开程序不再先烧 15 秒

| 项 | 以前 | 现在 |
|---|---|---|
| 启动时后台读列表元信息 | 前 12 个存档逐个全量解码，1.28s/档 ≈ **15 秒 CPU**，还顺手写 26MB×12 ≈ **300MB 磁盘** | 按 (路径, mtime, size) 缓存，**第二次开程序一次解码都不做**；扫元信息也不再写那 26MB |
| 所属方列表 `houses()` | 182ms / 大任务档 604ms，界面刷新一次要调 8 遍 | **0.0ms**（缓存结构，钱每次现读，改完立刻是新值） |
| 存档差异 `diff()` | 5~10 秒（26MB 逐字节 Python 循环） | **16ms**（按 64KB 块比） |

## 5. 高 DPI 屏不再糊

125% / 150% 缩放下以前整窗发虚。现在开了 DPI 感知，字体按原生分辨率渲染，
窗口和写死的像素宽度（列表卡、导航条）跟着缩放，并按屏幕可用区域封顶。
96 DPI 的机器上行为**完全不变**。

## 6. 打包相关的两处

- **崩溃日志真的会写了**：原来 `_install_crash_hooks()` 写在另一个入口文件里，

## 8. 升级提示

- 这是 **v1.3.0 之后的第一个功能版**（新页 + 四个 bug 修复 + 数据安全），建议直接替换。
- **铁律没变**：本工具**只读地图、只写存档**，任何情况下都不写 `.map/.mmx/.yrm/.mpr`。
- 改档前请备份（地图页有「备份存档」一键按钮）。
- 解压后**直接双击 `RA2存档编辑器.exe`**（`_internal` 目录要跟它同级，别只拷 exe）。
- 第一次开程序仍会为列表里的存档解码一次（拿任务名/金钱），之后就走缓存了。

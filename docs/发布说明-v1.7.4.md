## 换了新图标 🦅

程序图标换成了玩家提供的鹰形徽章（exe 资源、标题栏、任务栏、Alt+Tab 全部统一）。
`.ico` 里带 16/24/32/48/64/128/256 七档，Windows 按 DPI 自己挑，不再糊成一团。

## 保存更安全（这版最重要的部分）

| 以前 | 现在 |
|---|---|
| 原地保存失败时可能把**原档删掉** | 全程只写临时文件，失败时目标文件一个字节都不动 |
| 写盘不是原子的 | 临时文件 → 回读核对明文与块布局 → `os.replace` |
| 「另存为」覆盖已有文件时不备份 | 覆盖前先备份；备份失败就**中止保存**（没退路的覆盖比不保存更糟） |
| 保存那几秒里的编辑会被静默吞掉 | 检测到并发编辑会保留内存改动并明确提示"请再保存一次" |
| 保存卡住时看门狗会解除锁，可能两个线程同时写 | 只提示、不解除锁 |

## 打开坏档不再是天书

以前把 Python 的 traceback 原样弹出来（`struct.error: unpack_from requires a buffer...`）。现在：

- **空文件** → 这文件是空的（0 字节）→ 多半是写入被打断 → 去「_备份存档」找 `.bak-*`
- **不是存档** → 这不是红警2/尤里的复仇存档 → 文件只有 4 KB，请选 `.SAV`
- **被截断** → 存档文件不完整 → 复制/下载中断、U 盘拔早了、云盘只同步了一半
- **没权限** → 常见原因：只读属性 / 游戏开着占着 / 杀软拦截
- **磁盘满 / 内存不够** → 各自有对应说法

正文最后仍留一行「技术摘要」+ 完整日志路径（`%LOCALAPPDATA%\RA2SED_logs\`），报问题时把日志发来即可。

## 出了问题能看到原因（本轮工程改动）

- **静默异常记账**：全项目 313 处 `except ...: pass` 换成了统一的可观测版本。
  规则表没加载上、指纹缓存坏了这类"悄悄降级"，现在会记进日志；
  设计内的降级（utf-8→gbk、DLL→纯 Python 回退）单独归类，不会淹没有用信息。
- 取回路径四条：出错弹窗的日志 / `crash.log` / 命令行报告 / 正常关窗时的 `session-*.log`。
- **`--selftest-core`**：不建界面也能验核心链路（解码 / 改钱 / 写盘 / 触发），服务器和 CI 可用。

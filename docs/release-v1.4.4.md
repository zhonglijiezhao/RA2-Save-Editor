这一版全部围绕**关联触发**（FA2 的「关联触发」、存档记录帧 `+132`）展开：
以前只能"读出来标个（共用）"，现在能**双击打开、看清链路、直接改**；
顺带把「禁止触发」这类行为的参数从"永远是 0"修成"真的指向哪条触发"。

## 1. 双击触发行 = 打开触发编辑器

以前双击是「启用/禁用」开关，鼠标一滑就改掉了状态。现在：

- **双击触发行** → 直接打开触发编辑器，编辑的正是双击到的那一行；
- 双击**标签/AI 记录**行 → 仍是老规矩切换启用；双击表头不算；
- 开关留给**空格键**和下面两个按钮。

## 2. 「下级触发」：从"待样本"变成可读可写

编辑器里原来那一行只有一句 `（存档里未定位·待样本）`。现在是一整行控件：

- **只读下拉**列出全档触发（`〔自己有标签〕` 会标出来），`（无 · 链尾）` = 断开；
- **应用** = 只写**记录帧 `+132` 这 4 个字节**（实例键，0 = 链尾）。
  不增删对象、不动序号、长度不变 ⇒ **随时能改回来**；
- **跳到下级 →** 顺着链往下走，不用在下拉里翻；
- 下面一行给了链的位置：`上级 X · 下级 Y · 这条链共 N 条，本条第 i 条（链头 … 链尾）`。

安全阀：

- **成环 / 自指**直接拒绝（引擎沿 `+132` 走链，环会让它转不出去）；
- 目标已有另一条链指着（分叉，实档 0 例）先弹确认；
- 新建 / 复制触发**不再继承模板的链接**（以前克隆模板会把别人家的下级一起抄过来）；
- **删除触发时自动摘链**：`A→B→C` 删 B ⇒ `A→C`，不留"指不到任何触发"的野键。

## 3. 修：行为 53/54/12/22 的参数一直是 0

「允许触发 / 禁止触发 / 摧毁触发 / 强制触发」这四个行为的参数是**另一条触发**，
可它**不在通用参数槽 `+72`**，而在对象 **`+100`**（u32 实例键）。
以前一律读 `+72`（恒 0）⇒ 界面上看不出"禁止谁"，改参数也不生效。

- 行为列表的参数列现在显示目标触发 ID，含义列显示 `01000004 CCCCC（自己）`；
- 参数框变成**触发下拉**（含「（自己）」项），改它写的就是 `+100`；
- 跨 4 档 **700 条**触发型行为实测：`+100` 命中本档实例键 100%，0 个 0、0 个野值。

## 4. 谁会被上级拖死：三种口径（三轮修正后定案）

「关联触发」的**本质是共享挂接对象**，不是"执行顺序"——因为**一个建筑只能挂一个标签**。
想让同一栋楼"进楼做一件事、被摧毁时做另一件事"，就做成 A(进入) → B(摧毁) 的下级链：
B 自己那份标签不挂任何对象，它"摧毁谁"是通过链共享 A 的挂接对象得到的。

于是"上级被禁用/删除后下级还活不活"要分三种：

| 下级情况 | 结果 |
|---|---|
| 事件是**流逝时间 / 局部变量**这类（不需要挂接对象）+ **有自己的标签** | **不受上级限制**（这套写法对它没意义） |
| 事件要**挂接对象**（进入 / 被摧毁 / 被攻击…） | 挂接对象来自上级的标签 ⇒ 上级被禁用/删除就不触发 |
| **没有自己的标签**（写 A：整条链共用链头那个） | 无论什么事件，命都在链上，上游一停就没了 |

界面上怎么体现：

- 触发页状态列会直接写 `上级已禁用·永不触发（<链路头 sid>）`——**只在这些情况**；
- 编辑器状态行最前面加 `⚠ 上级 X 已禁用 ⇒ 本条永远不会触发`，链路提示按上表分三支；
- **禁用**前弹连带名单（只列真会死的那些），**软删/真删**对话框也列同一份名单；
- 反过来，从链尾往上级删不影响前面。

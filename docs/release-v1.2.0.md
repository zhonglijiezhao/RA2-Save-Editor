## v1.2.0（内部构建 p218）

本次新增「地图页直接编辑单位」的全套功能，并修掉一个会让大家放了单位却显示新兵的老 bug。

### 新增

- **单位：复制 / 粘贴 / 移动**（地图页 →「单位操作」那一排）
  - `📋 复制该格` → 记下该格全部单位（类型 / 所属方 / 等级）
  - `📌 粘贴到此格` → 在目标格克隆一份（源保留）
  - `➡ 把源格单位移到此格` → 真正搬过去（改写位置的 6 处副本，记录长度不变）
  - 按**格**操作，同格多台一起处理；移动后源格清空、格占用跟着换
- **单位：删除该格单位**
  - 真删记录（主体 + 伴随），并同步清掉：两张全局指针表条目、阵营对象表条目、格占用
  - 删除前会**体检引用**：如果别的建筑正瞄着它（`+0x1B0` 目标指针），会把清单列给你看并清 0
  - 同格多台一起删安全（每台重新定位偏移）
- **地图页显示单位**：勾选框「单位（≥20 倍）」，默认关闭；勾上会自动放大到 20 倍，
  琥珀色方块标出每台单位，同格多台标 ×N
- **地图页显示路径点**：勾选框「路径点」，默认开启
  - 绿底白字圆 = 地图 `[Waypoints]` 定义的号（填「出现于 / 运输机起始」要用这批）
  - 空心蓝框 = 只有存档里才有的点（引擎运行期生成）
  - 点格子会直接报该格的路径点号

### 修复

- **等级选择无效（放出来全是新兵）** —— 这是个老 bug：
  以前写等级时把 `+0x164` 也一起写成 `float(2-等级)`，而游戏里真实的精英是 `+0x164=2.0`。
  改错这一列后引擎判定状态异常、按默认重算，于是显示新兵。
  现在**只写 `+0x150`**，`+0x164` 原样保留 —— 与游戏内手工升级出来的单位状态完全一致。
- **55 台单位在地图上"消失"**：原来只按 `+224` 格键查坐标，查不到就当成没有坐标。
  现在用 `+1392/+1394`（u16 格坐标）兜底，这些单位（含基地车这种）能正常显示与操作了。
- **路径点/单位的落点提示**：点格子时信息栏会列出该格的单位类型与路径点号。

### 说明

- 删除单位会改变存档明文长度（每台约 −1.9KB），全档偏移会重算。
  **删之前请先点一次「备份存档」**，并建议先另存为新文件再进游戏验证。
- 「科技等级 / 运输机类型 / 无视离子风暴 / 运输机下客后返回」仍未支持（待定中）。
